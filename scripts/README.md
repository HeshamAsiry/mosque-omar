# ملاحظة مهمة

كل ملفات `fix-*.mjs` في هذا المجلد كانت تُستخدم سابقًا أثناء `npm run build`
لتعديل `src/main.jsx` و`src/styles.css` و`src/branding.css` تلقائيًا (كل سكريبت
يضيف Patch فوق الآخر بالترتيب المحدد في `package.json`).

بتاريخ إعادة تصميم الواجهة (أغسطس 2026)، تم:

1. تشغيل كل هذه السكريبتات بالترتيب الأصلي على نسخة من المصدر للوصول
   للنسخة النهائية الحقيقية التي كانت تظهر فعليًا للمستخدم.
2. حفظ تلك النسخة مباشرة كمصدر أساسي في `src/main.jsx`.
3. إعادة بناء `src/styles.css` و`src/branding.css` بالكامل كنظام تصميم
   موحّد (Design Tokens)، مع الحفاظ على **كل** أسماء الأصناف (class names)
   نفسها حتى لا يحتاج JSX لأي تعديل.
4. تبسيط `scripts.build` في `package.json` إلى `vite build` فقط، لأن كل
   التعديلات التي كانت تضيفها هذه السكريبتات أصبحت جزءًا دائمًا من المصدر.

**السكريبتات هنا لم تعد تُستدعى من الـ build، وتُركت فقط كمرجع تاريخي.**
لا تضف سكريبت `fix-*.mjs` جديدًا — عدّل `src/main.jsx` أو ملفات CSS مباشرة.
