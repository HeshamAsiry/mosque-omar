# نظام الكفالة والمساعدات

Web App لإدارة حالات المساعدات وكفالة الأيتام.

## الأهداف

- تسجيل دخول وصلاحيات مستخدمين.
- قاعدة بيانات مركزية مع مزامنة لحظية بين المستخدمين.
- تصميم Mobile-first يعمل على الهاتف والكمبيوتر.
- إدارة الأمهات والحالات والأطفال.
- قائمة انتظار بأولوية تلقائية قابلة للمراجعة من Admin.
- حساب المبالغ تلقائيًا مع إعدادات مبالغ قابلة للتعديل.
- Dashboard وتقارير وسجل تعديلات.

## بيانات الحالة

البيانات الأساسية المطلوبة للأم:

- اسم الأم
- رقم الهاتف
- العنوان
- نوع الحالة: مساعدات أو كفالة أيتام
- ملاحظات اختيارية

وعند اختيار كفالة أيتام، لكل طفل:

- الاسم
- النوع: ذكر أو أنثى
- تاريخ الميلاد

تطبيق حد 18 سنة يكون على الذكور فقط، مع استمرار الإناث وفق قواعد الكفالة المعتمدة.
